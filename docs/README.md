## 🎯 What is Alasmia?

Alasmia is an **AI Life Partner** that:
- 💜 Remembers everything about you
- 🤖 Reaches out proactively (doesn't wait for you)
- ⏰ Available 24/7
- 🎭 Understands emotions
- 🌐 Works on Telegram, WhatsApp, CLI
